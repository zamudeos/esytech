# Repository Instructions

## ESY Blog Content Rules

- Never publish blog content directly.
- Always create a draft and Pull Request.
- Never modify unrelated website sections.
- Use reliable primary or official sources for current claims.
- Use at least two reliable sources for current security or scam alerts whenever possible.
- Never invent statistics.
- Never copy source text.
- Do not reuse copyrighted images.
- Generate original SVG covers by default.
- Clearly label sponsored or affiliate content.
- Avoid clickbait.
- Avoid absolute security guarantees.
- Use English for the current website version.
- Check existing posts before proposing a new article.
- Update an existing article instead of creating duplicate content.
- One proposed article maximum per scheduled run.
- Preserve source attribution.
- Require human approval before publishing.
